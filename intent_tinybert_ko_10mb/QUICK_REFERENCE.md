# Korean Intent Recognition - Quick Reference

## 🚀 Quick Start (5 minutes)

### 1. Install Dependencies
```bash
cd intent_tinybert_ko_10mb
pip install -r requirements.txt
```

### 2. Preprocess Data
```bash
python src/preprocess.py
```
Output: `data/processed/data.csv`, `data/processed/label_maps.json`

### 3. Train Model (⏱️ 25 min GPU / 3 hrs CPU)
```bash
python src/train.py
```
Output: `outputs/runs/run_001/best_model/`

### 4. Evaluate
```bash
python src/evaluate.py
```
Output: `outputs/runs/run_001/metrics_eval.json`

### 5. Export (for deployment)
```bash
python src/export_fp16.py
```
Output: `outputs/exports/fp16_span_model/` (10 MB)

### 6. Run Inference
```bash
python src/infer_json.py
```

## 🎯 What This Project Does

Extracts 6 types of information from Korean UI commands:

```
Input:    "마지막 회색 탭 3번 클릭"
          (click the 3rd gray tab)

Output:   {
            "intent": "click",
            "target_type": "tab",
            "attribute": "gray",
            "position": "3rd"
          }
```

---

## 🇰🇷 Korean Terms Supported

### UI Elements
textbox, checkbox, radiobutton, button, tab, menu, dropdown, list, text, link, icon, item

### Colors
red, blue, green, yellow, black, white, gray

### Spatial Relations
above, below, left_of, right_of, next_to, inside, from_left, from_right

### Positions
1st, 2nd, 3rd, 4th, 5th, last, top, bottom, middle

## 🔧 Configuration

### Key Parameters (in `src/train.py`)

```python
MODEL_NAME = "kykim/bert-kor-base"  # Korean BERT
MAX_LEN = 64                        # Max tokens
num_train_epochs = 3                # Epochs
per_device_train_batch_size = 32    # Batch size
learning_rate = 2e-5                # LR
```

### To use CPU instead of GPU
```bash
# Set environment variable
CUDA_VISIBLE_DEVICES=-1 python src/train.py
```

### To reduce memory usage
Change batch size in `train.py`:
```python
per_device_train_batch_size = 16  # Reduce from 32
```

## 🧠 Model Architecture

```
Korean Command Text
    ↓
Tokenize with kykim/bert-kor-base
    ↓
BERT Encoder (768 hidden, 12 layers)
    ↓
┌────────────────────┬─────────────────┐
↓                    ↓
CLS Token         Token Sequence
    ↓                    ↓
┌──────────────────────┐  Span Head
│ Classification Heads │    ↓
│ ├─ Intent          ├──→ Start Logits
│ ├─ Target Type    │  ┴→ End Logits
│ ├─ Attribute      │
│ ├─ Spatial Rel    │
│ └─ Position       │
└──────────────────────┘

Output: 5 classes + 2 span predictions
```

### Korean characters not showing

```python
df = pd.read_csv("file.csv", encoding='utf-8')
df.to_csv("file.csv", encoding='utf-8')
```

### Out of memory
```bash
# Reduce batch size
# In train.py: per_device_train_batch_size = 16
```

### CUDA errors
```bash
# Force CPU
CUDA_VISIBLE_DEVICES=-1 python src/train.py
```

### Import errors
